## Project Overview

Open-nof1.ai is an open-source AI crypto trading benchmark platform. It gives an AI model (DeepSeek) $10k USDT and lets it trade cryptocurrency perpetual contracts on Binance in real markets. Every decision, prompt, and reasoning chain is logged for full transparency.

## Commands

```bash
bun install                  # Install dependencies
bun dev                      # Dev server with Turbopack (http://localhost:3000)
bun build                    # Production build
bun start                    # Start production server
bun lint                     # ESLint
bunx prisma generate         # Generate Prisma client
bunx prisma db push          # Push schema to database
```

Docker:
```bash
docker compose up --build -d
docker compose exec app bunx prisma db push
```

No test framework is configured.

## Architecture

**Full-stack Next.js 15 App Router** with Bun runtime, PostgreSQL (Prisma ORM), and Vercel AI SDK.

### Core Loop

Two cron-triggered API endpoints drive the system:

1. **Every 20 seconds** (`/api/cron/20-seconds-metrics-interval`) - Collects account snapshots (balance, positions, PnL) into the `Metrics` table. Capped at 100 entries with uniform sampling.
2. **Every 3 minutes** (`/api/cron/3-minutes-run-interval`) - Executes `lib/ai/run.ts`: fetches market data + account state, sends to DeepSeek with a trading system prompt, receives a structured BUY/SELL/HOLD decision via Zod schema validation, stores reasoning in `Chat` and trades in `Trading` tables, then executes the trade via CCXT.

Cron endpoints are authenticated via JWT tokens (generated by `scripts/generate-jwt.js`, verified against `CRON_SECRET_KEY`).

### Key Directories

- **`lib/ai/`** - LLM integration: model config (`model.ts`), system/user prompts (`prompt.ts`), trading execution loop (`run.ts`). Uses Vercel AI SDK `generateObject()` with Zod schemas for structured output.
- **`lib/trading/`** - Market data via CCXT (Binance): technical indicators (EMA, MACD, RSI, ATR from `technicalindicators` lib), account info, buy/sell execution. Exchange client configured in `binance.ts`.
- **`app/api/`** - API routes: cron handlers, metrics serving, crypto pricing, chat history.
- **`components/`** - React dashboard: metrics chart (Recharts), trade history, crypto price cards. Uses shadcn/ui.
- **`prisma/schema.prisma`** - Three models: `Metrics` (account snapshots), `Chat` (AI decisions with reasoning), `Trading` (individual trades). Chat has one-to-many relation to Trading.

### AI Model Configuration

Models are defined in `lib/ai/model.ts`. Currently uses DeepSeek natively (`@ai-sdk/deepseek`) with OpenRouter as fallback (`@openrouter/ai-sdk-provider`). The `ModelType` enum in Prisma supports: Deepseek, DeepseekThinking, Qwen, Doubao. New models can be added via [AI SDK providers](https://sdk.vercel.ai/providers/ai-sdk-providers).

### Dashboard

`app/page.tsx` is a client component that polls `/api/metrics` and `/api/pricing` every 10 seconds. Displays account performance chart, live crypto prices (BTC/ETH/SOL/BNB/DOGE), completed trades, and AI reasoning history.

## Notable Conventions

- Path alias: `@/*` maps to project root
- Prisma singleton pattern in `lib/prisma.ts` (avoids connection exhaustion in dev)
- The enum `Opeartion` (typo for "Operation") is used consistently throughout the schema and codebase - maintain this spelling
- Styling: Tailwind CSS v4 with shadcn/ui components (configured in `components.json`)
- `BINANCE_USE_SANDBOX=true` for testnet; `false` for live trading
